# Проектная работа «Закрывающий тег»

## Описание проекта

Небольшой одностраничный проект, выполненный в рамках обучения в Яндекс Практикуме.

Проект представляет собой набор карточек, отражающих этапы обучения и эмоциональное состояние во время прохождения курса. Основная идея — показать путь от первых шагов в вёрстке до завершения обучения через изображения, фильтры и визуальные эффекты.

## Особенности проекта

- адаптивная вёрстка;
- пиксель-арт стилистика;
- CSS-фильтры и эффекты;
- анимация лайка;
- модальное окно (`dialog`);
- SVG-иконки;
- использование CSS-переменных;
- работа с `mix-blend-mode`;
- плавные hover-эффекты и transitions.

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- SVG

## Что было реализовано

- карточки с уникальными визуальными состояниями;
- кастомные фильтры изображений;
- кнопка лайка с изменением состояния;
- переиспользуемые компоненты;
- стилизованное модальное окно;
- работа с псевдоэлементами;
- использование flexbox-layout.
